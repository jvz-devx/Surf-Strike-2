# Credits

## Sounds

Every game sound is a real recording released under **CC0 1.0** (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/). No attribution is legally required; it is given here anyway. The licence was checked on each sound's own Freesound page. Source files are the Freesound HQ preview MP3s (`https://cdn.freesound.org/previews/...-hq.mp3`).

`tools/audio/process.py` turns them into the shipped files in `apps/web/static/sfx/`. All trim points, fades and levels are in `tools/audio/manifest.json`. Every file gets the same treatment: mono downmix for events, 30 Hz high-pass, a 1–50 ms fade-in at the transient, a sine fade-out, loudness matching within its pool, true peak ≤ −1.5 dBTP, and AAC encoding in `.m4a` (48 kHz). No pitch shifting, no synthesis. The combat pools (from "Pistol shot" down) were added on 2026-11-23 with `process.py --only`, which leaves the older files byte-identical; their rows carry the date the licence was read.

## Models

Every first-person gun is an original model built by a Blender script in this repository (`tools/models/procedural/`: one script per gun and the shared `common.py`), with no external source: shapes from primitives, bevels and boolean cuts, textures baked with Cycles with an edge-wear and grime pass, shipped with meshopt geometry and WebP textures. `tools/models/procedural/build.sh` rebuilds them.

The knife is the one generated model: made with Tripo H3.1 image-to-3D (on fal.ai, PBR) on 2026-11-23 from a public-domain photo on Wikimedia Commons (licence read on its Commons page on 2026-11-23). `tools/models/build.sh` turns it so the blade points forward, puts the tip at the origin, scales it to length 1 and writes the shipped file (settings in `tools/models/manifest.json`). The claws and the throwing knife of the infected stay code-built, and so does every weapon other players hold.
